- ✓ 정적 wake.prompt 템플릿은 영속화 대상이 아니다 — wake prompt 141개는 각각 해시는 다르지만 확인한 내용은 타임스탬프·reason·meeting 경로 외에 동일한 대형 템플릿이었다. 템플릿을 버전 관리하고 가변 파라미터만 기록하면 전체 파일 반복 저장을 피할 수 있다. 다만 완전 재현을 요구한다면 템플릿 버전과 당시 파라미터가 함께 보존되어야 한다.
- ✓ 보존정책은 예방의 보완: 남기는 텔레메트리엔 TTL/rotation 적용 — 97MB npm-run-dev.log가 존재하고 이미 Git에서는 ignored이므로, 이는 Git 오염보다 로컬 디스크 보존 문제다. 유용한 로그도 무한 누적되므로 size rotation과 TTL은 필요하다. 다만 이를 메모리 부담이라고 부르는 것은 부정확하며, 구체적인 N일·M크기는 장애 분석 기간과 저장 예산을 근거로 정해야 한다.
